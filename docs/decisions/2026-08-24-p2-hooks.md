# P2 hooks 第五阶段决策

## 已实现

- `internal/hooks` 提供一个默认关闭的 metadata-only 外部事件观察器。
- 观察发生在事件成功写入 SQLite 之后，不参与回滚，也不能修改 session log、工具白名单或模型请求。
- hook 通过 `exec.Command` 直接启动，禁止 shell 命令行解释；进程使用超时、脱敏环境，并在应用关闭时 cancel + drain。
- 默认不传输事件正文。stdin 只包含 `session_id`、`event.seq`、`event.type`、`event.at` 和 `event.version`，不会包含消息文本、工具参数、工具结果或任意 `event.data`。
- `hooks.events` 可限制事件类型；`hook/*` 事件永远不会再次触发 hook，避免递归。

## 配置

```yaml
hooks:
  enabled: true
  command: "my-hook"
  args: []
  events: ["turn/end", "tool/result"]
  timeout_ms: 10000
```

## ACP/SDK 边界

现有 `internal/webserver` 已提供 bearer 认证的 HTTP 工作台 API，可作为本地程序化入口。完整 ACP 仍单独保留：它需要 JSON-RPC stdio transport、session/new/prompt/cancel 所有权、通知顺序、权限请求和断连清理；本阶段不伪造一个不完整协议实现，也不把它耦合进 REPL loop。
